Excel Data Sync
Keep an offline Excel workbook in sync with this dashboard's data
How this works: everything in this dashboard lives in your browser only. Use Export to save a full Excel workbook you can archive, edit offline, or hand to your accountant. Use Import to bring a workbook back in — matching rows (by ID) are updated, new rows are added. Always keep a backup copy before importing.
Export to Excel ⬇

Downloads one .xlsx workbook with separate sheets for Occupants, Cabins, Payments, Sales Leads and Invoices — the full dataset behind this dashboard.

Just need the pending-payments list? Head to Payments for a CSV export of every due/overdue invoice with due dates and payment links.

Import from Excel ⬆

Upload a workbook exported from this dashboard (or built to match its column layout). Rows are matched by their id column — existing records get updated, unmatched rows are added as new.

Workbook Sheet Reference
Occupantsid, name, company, email, phone, address, cabins, seatAllocationsJson, start, end, rent, deposit, advance, parking, escalation, upiId, reminderSent
Cabinsid, floor, seater, sno, occupied, occupantId, occupantName, note
Paymentsid, occupantId, month, amountDue, baseAmount, amenitiesJson, dueDate, paidDate, reminderSent, reminderDraftedAt, notes
Leadsid, name, company, phone, email, source, agencyName, stage, seats, notes, created, nextFollowUp, activitiesJson
Invoicesid, invoiceNo, date, occupantId, buyerName, buyerAddr, buyerGstin, buyerState, buyerContactPerson, buyerContactPhone, agreementRef, paymentTerm, otherRef, dispatchedThrough, destination, itemDesc, itemHsn, itemGstRate, itemQty, itemRate, itemPer, itemAmount, itemsJson, cgstPct, sgstPct, notes, status, paymentStatus, createdAt, sentAt, receivedAt, periodMonth
Tip: add an optional upiId value on any Occupants row to give that tenant their own collection UPI ID — reminder emails use it instead of the dashboard-wide default automatically.
Tip: for Invoices, leave id blank on new rows so they're added rather than merged. For a simple single-line invoice you only need invoiceNo, date, buyerName, itemDesc, itemAmount — leave itemGstRate blank to default to 18%, or set it to 0 for a tax-exempt line. Only fill in itemsJson if an invoice has more than one line item (it's a JSON array and overrides the flat item* columns when present).
